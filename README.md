# Programação Orientada a Objetos (POO) — PROA

Repositório com 2 exercícios práticos desenvolvidos durante o curso **PROA**, com foco em Programação Orientada a Objetos (POO) utilizando JavaScript.

## Sobre o projeto

As atividades têm como objetivo praticar os fundamentos da orientação a objetos, compreendendo como estruturar e organizar o código por meio de classes e objetos.

## Exercícios

O repositório contém 2 exercícios, cada um abordando situações práticas para aplicar os conceitos de POO em JavaScript.

## Como executar

Para testar um exercício:

1. Abra o arquivo com os códigos dos exercícios.
2. Localize a função que deseja testar.
3. Leia o comentário que identifica o número e o objetivo do exercício.
4. Descomente a chamada da função logo abaixo dela.
5. Execute o programa para visualizar o resultado.

**Observação:** Para testar outro exercício, basta comentar novamente a chamada anterior e descomentar a desejada.

## Conteúdos praticados

- Programação Orientada a Objetos (POO)
- Classes e objetos
- Atributos e métodos
- Construtores
- Organização e reutilização de código
